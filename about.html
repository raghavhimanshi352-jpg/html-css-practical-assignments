About this project

This project is a practice portfolio for learning semantic HTML, accessible forms, CSS layouts and responsive design.

Learning goals

  • Write valid HTML5 structure.
  • Use semantic elements and accessible labels.
  • Style pages with reusable CSS variables.
  • Build layouts using Flexbox and CSS Grid.
  • Test layouts on mobile and desktop widths.
