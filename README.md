# HTML & CSS Practical Assignments

A beginner-friendly project containing 45 numbered practice pages across nine modules.

## Modules
1. Setup & Git (01–05)
2. HTML Basics (06–10)
3. Links, Images & Lists (11–15)
4. Forms, Tables & Metadata (16–20)
5. CSS Fundamentals (21–25)
6. Box Model & Positioning (26–30)
7. Flexbox (31–35)
8. CSS Grid (36–40)
9. Responsive Design & Integration (41–45)

## Run locally
1. Download or extract the project folder.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code.
3. If Live Server is installed, right-click `index.html` and choose **Open with Live Server**.
4. Open numbered assignment files inside the module folders.

## Important notes
- Replace sample and placeholder details with your own accurate information before submitting.
- Forms in this practice project are front-end demonstrations only; they do not send data to a server.
- Assignments 2 and 5 ask for proof of your own software setup and GitHub repository. Add your real screenshots and repository link after completing those steps.
- Some module-specific CSS examples are provided in separate CSS files. Link them to the relevant page if you want to test the advanced examples.

## Upload to GitHub
Create a repository named `html-css-practical-assignments`, then upload the contents of this folder (including `README.md`, `index.html`, `styles.css`, and all module folders). Do not upload the ZIP file as the only repository content if your teacher expects to inspect individual source files.
